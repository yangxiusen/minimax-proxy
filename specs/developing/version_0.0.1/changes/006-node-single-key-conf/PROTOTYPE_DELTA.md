| 项目 | 内容 |

## 2. 原型目标

本次是既有表单字段收敛，不改变导航、页面结构或主流程，因此不更新长期产品原型文件。该增量明确删除 Key ID 后的字段、校验和编辑复用行为，避免前后端再次产生契约偏差。

## 3. 变更页面清单

| --- | --- | --- | --- |
| 节点管理表单 | 顶部“节点管理”入口 | 删除 Key ID；API Key 限定 32 位字母数字 | 创建、编辑、连接测试共用 |

## 4. 交互说明

### 4.1 正常流程

1. 管理员打开节点管理并新建或编辑 H3 节点。
2. 新建或 Legacy 升级时填写一个 32 位 API Key；编辑已有 H3 节点时可留空。
3. 保存或连接测试成功后，页面继续保持 Key 明文不可回显。

### 4.2 异常与边界

- 加载态：沿用现有节点列表和表单加载反馈。
- 空态：沿用现有无节点状态。
- 错误态：Key 非 32 位或包含非字母数字字符时，在提交前由浏览器校验，服务端仍返回稳定 400 错误。
- 权限限制：继续使用 Manager 登录会话，不新增角色。
- 禁用态：请求进行中沿用现有按钮禁用策略。
- 编辑态：Key 输入始终为空，提示“编辑时留空表示沿用已保存 Key”。

## 5. 视觉和文案补充

- 删除“Key ID”标签和输入框。
- “API Key”使用密码输入框，设置 `minlength=32`、`maxlength=32`、`pattern=[A-Za-z0-9]{32}`。
- 不新增卡片、弹窗或说明性功能文案，不改变现有视觉语言。

## 6. 对接准备说明

- 关联接口：`POST /manager/api/nodes`、`PUT /manager/api/nodes/{id}`、节点连接测试接口。
- 关键字段：只保留 `api_key`，移除 `api_key_id`。
- 人工关注：创建、编辑留空复用、Legacy 升级、连接测试与错误提示；操作过程不得在截图中展示密钥。

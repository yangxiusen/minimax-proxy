# Manager 任务详情与物理删除原型增量

## 1. 影响页面

| 页面 | 变化 |
| --- | --- |
| `/manager/` 任务列表 | 操作列新增“查看”按钮 |
| 任务详情弹窗 | 新增弹窗，展示请求内容、媒体输入和配置摘要 |
| 删除确认框 | 文案改为物理删除提醒 |

## 2. 任务列表操作列

每行操作顺序建议：

1. 成功任务有视频时显示“播放”。
2. 所有未物理删除任务显示“查看”。
3. 可中止任务显示“中止”。
4. 可删除终态任务显示“删除”。

按钮状态：

| 按钮 | 可用条件 | 禁用或隐藏 |
| --- | --- | --- |
| 查看 | 任务存在于列表 | 请求详情加载中时禁用当前按钮 |
| 删除 | `can_delete=true` | 非终态任务隐藏 |
| 中止 | `can_cancel=true` | 正在操作中禁用 |

## 3. 任务详情弹窗

弹窗标题：
`任务 <task_id> 请求详情`

推荐分区：

| 分区 | 字段 |
| --- | --- |
| 基本信息 | 任务 ID、客户 Key、状态、场景、创建时间、更新时间 |
| 生成设置 | 模型、逻辑分辨率、比例、时长、水印、配置版本 |
| 文案 | 用户提交的 text 内容，保留换行 |
| 媒体输入 | 类型、角色、来源、MIME、大小、sha256 前缀、文件状态 |
| 配置摘要 | model mode、steps、cache mode、LoRA、插帧、修复 |
| 提示 | 历史 Base64 隐藏提示、文件缺失提示 |

展示细节：

- 长文案使用可滚动 `<pre>` 或等价块，避免撑破页面。
- 媒体输入使用紧凑列表，不在表格中放完整长 URL。
- `source_kind=data_uri` 显示“本地临时文件”，不显示绝对路径。
- `source_kind=http_url` 显示 URL，可根据现有日志安全规则进行中间截断。
- 文件大小使用已有 `bytesLabel`。
- 文件不存在时显示“文件缺失，任务可能无法继续执行”。
- 历史任务含 Base64 时显示“历史任务含 Base64，后台已隐藏正文”。

## 4. 删除确认文案

现有：
`确认删除任务 <task_id>？`

改为：
`确认物理删除任务 <task_id>？该操作会删除数据库记录和本地临时输入文件，不可恢复。`

如果任务有成功产物，可追加：
`系统会先删除对应节点上的受管产物；节点不可达时删除会失败，请稍后重试。`

如果任务仍在中止对账中，删除接口返回 409，前端提示：
`任务仍在中止对账中，节点确认停止后才能删除。`

## 5. 加载、空态和错误态

| 场景 | 展示 |
| --- | --- |
| 详情加载中 | 弹窗骨架或“正在加载请求详情...” |
| 详情加载失败 | “请求详情加载失败，请刷新后重试” |
| 无媒体输入 | “无图片或音频输入” |
| 历史 Base64 已隐藏 | 醒目但不阻断的提示 |
| 删除远端失败 | alert 或行内错误：“远端文件删除失败，请稍后重试” |
| 中止对账未完成 | alert 或行内错误：“任务仍在中止对账中，稍后再删” |

# 对外 API Key 管理原型增量

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 目标版本 | `version_0.0.1` |
| 变更编号 | `005-api-key-management` |
| 原型范围 | 顶栏入口、密钥管理弹窗、一次性 Key 弹窗 |
| UI 变化等级 | 局部交互增量，非导航或主页面结构重大变化 |

## 2. 原型目标

在不扩张任务监控主页面的前提下，为管理员提供紧凑、明确的外部 Key 生命周期入口，并通过一次性展示降低泄密风险。

## 3. 变更组件

| 页面或组件 | 入口 | 变更点 | 运行时文件 |
| --- | --- | --- | --- |
| Manager 顶栏 | `/manager/` | 新增“密钥管理”按钮，与“节点配置”同级 | `internal/httpapi/manager/web/manager.html` |
| 密钥管理弹窗 | 顶栏按钮 | 列表、启用统计、空态、创建和行操作 | `manager.html`、`manager.js`、`styles.css` |

| 删除确认 | 列表删除按钮 | 显示名称/掩码；引用冲突引导停用 | 同上 |

本次不是界面重大变化，不要求重做 `specs/product/admin` 的长期原型目录。brainstorming 选择稿位于被 `.gitignore` 排除的 `.superpowers/brainstorm/`，仅作为发现阶段临时材料。

## 4. 交互说明

### 4.1 正常流程

1. 管理员点击顶栏“密钥管理”。
2. 页面加载列表并显示“启用 N 个”。
3. 管理员点击“创建密钥”，输入名称并提交。
4. 页面只展示一次完整 Key，并提供复制按钮。
5. 管理员确认已保存后关闭一次性弹窗，列表只保留掩码。
6. 重命名、启停和删除后刷新当前行版本及顶部统计。

### 4.2 状态与边界

- 加载态：列表区域显示“正在加载密钥”，操作按钮禁用。
- 空态：显示“暂无对外 API Key”，保留主创建按钮。
- 零启用态：顶部展示警告“当前无可用对外密钥，所有 V2 Bearer 请求将被拒绝”。
- 名称冲突：保留输入并显示“名称已存在”。
- 版本冲突：提示配置已变化并重新加载列表。
- 删除冲突：显示“该密钥仍有关联任务或幂等记录，请停用后保留”。
- 缓存刷新失败：显示操作未完成的服务异常，不显示或记录任何 Key。
- 会话失效：沿用现有逻辑跳转 `/manager/login`。

## 5. 视觉与文案

- 沿用当前后台按钮、对话框、状态色、8px 以内圆角和紧凑间距。
- 状态使用“已启用 / 已停用”，危险操作使用现有红色按钮样式。
- 复制按钮使用已有图标库时采用复制图标；否则使用明确“复制”命令并提供成功反馈。
- Key 掩码示例：`mmx_ab12...89ef`。
- 完整 Key 使用等宽字体和可横向滚动容器，不允许文本撑破弹窗。
- 不在主页面增加常驻密钥卡片，不显示功能说明性营销文案。

## 6. 对接准备

- 关联接口：`GET/POST/PUT/DELETE /manager/api/api-keys`。
- 关键字段：`id`、`name`、`masked_key`、`enabled`、`version`、创建响应 `key`。
- 自动页面测试需验证脚本不通过 `innerHTML` 插入 Key，关闭后 DOM 不保留完整值。
- 人工验收需验证复制按钮、关闭确认、零启用警告和移动端文本不溢出。

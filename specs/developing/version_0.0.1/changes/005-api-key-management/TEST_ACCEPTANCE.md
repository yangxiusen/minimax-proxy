## 6. 安全检查

- [ ] 浏览器网络面板中完整 Key只出现在创建响应。
- [ ] 关闭一次性弹窗后 DOM、JS 状态和浏览器存储无完整 Key。
- [ ] 服务日志不含完整 Key、摘要、Authorization Header 或请求体。
- [ ] SQLite 文本/十六进制搜索无法找到完整 Key。
- [ ] 禁用 Key 对任务 API 和 Bearer 文件下载均失效。
- [ ] Manager Session 与外部 Bearer Key 仍不可互换。

## 7. 回归与残余风险

- [ ] 原有任务创建、查询、列表和取消/删除正常。
- [ ] 签名文件下载正常。
- [ ] 节点配置、请求配置和视频清理后台功能正常。
- [ ] YAML 节点一次性导入不受本次 Key 导入标记影响。
- [ ] 单 Proxy 进程独占 SQLite 的部署约束已在运维说明中确认。

残余风险：创建响应在客户端收到前断线时，完整 Key无法恢复；管理员需删除无引用记录并重建。多进程共享数据库不受支持。

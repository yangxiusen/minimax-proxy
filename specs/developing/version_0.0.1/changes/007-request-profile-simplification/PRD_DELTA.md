# 模型请求配置简化 PRD 增量

## 1. 产品规则

- 一个请求分辨率只维护一份配置，没有草稿、发布版本或历史版本。
- 保存即生效，删除即失效，仅影响保存/删除之后创建的任务。
- 配置不区分文生、图生和全能参考；任务场景由输入内容自动识别。
- 管理员无需进行配置测试和发布操作。

## 2. 页面字段

保留：请求分辨率、模型模式、采样步数、SageAttention、缓存模式、7 种比例基础尺寸、LoRA、补帧、高清修复。

删除：模型、场景、主模型、生成帧率、CFG、AIGC 水印、版本、状态、测试、发布和复制。

“请求分辨率”的说明为：用于匹配公开任务请求；实际生成宽高由比例映射决定。

## 3. 操作

- `新建配置`：选择尚未配置的请求分辨率并保存，立即生效。
- `保存修改`：覆盖当前请求分辨率配置，立即生效。
- `删除配置`：二次确认后物理删除；不检查运行中任务。
- 已存在配置的请求分辨率不可在编辑时改名，避免含糊的覆盖行为；需要换档位时删除后新建。

## 4. 水印

水印不属于请求分辨率配置。公开任务传 `aigc_watermark=true` 才添加；省略或 false 均不添加。

# 模型请求配置页面原型增量

## 1. 页面结构

- 左侧配置列表最多显示三项：`480P`、`768P`、`2K`，不显示版本和状态。
- 右侧表单顶部为“请求分辨率”；编辑已有配置时只读，新建时只列出尚未配置的档位。
- 删除模型、场景、主模型、生成帧率、CFG、水印控件。
- 删除测试动作、发布门禁、发布和复制按钮。
- 底部命令为删除、保存修改；新建态为取消、创建配置。

## 2. 交互状态

| 状态 | 行为 |
| --- | --- |
| 空态 | 显示“暂无请求配置”和新建命令 |
| 新建 | 只允许选择未配置 resolution；保存后立即出现在列表 |
| 编辑 | 保存立即生效；成功后刷新行版本和更新时间 |
| 删除 | 二次确认；成功后选择下一项或进入空态 |
| 冲突 | 自动加载最新配置并提示已刷新，不覆盖他人修改 |
| 请求中 | 禁用表单和命令，保持固定布局 |

## 3. 文案

- 标签：`请求分辨率`
- 辅助说明：`用于匹配公开视频请求；实际生成宽高由比例映射决定。`
- 保存成功：`配置已保存并立即生效`
- 删除确认：`删除后该分辨率的新任务将无法创建，已创建任务不受影响。`

## 4. 响应式要求

桌面和移动视口均不得出现横向溢出；比例映射在窄屏换行，最长错误文案不遮挡操作按钮。

# 音频 Base64 输入测试与验收准备

自动化验证已通过；真实私有服务生成与生产环境限制仍待人工确认。

## 1. 自动化测试范围

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| AB-001 | 合法 `audio/wav` Data URI | 创建请求校验通过 |
| AB-002 | 合法 `audio/mpeg` 和 `audio/mp3` Data URI | 创建请求校验通过 |
| AB-003 | 空内容、非法 Base64、错误 MIME、裸 Base64 | 返回明确参数错误 |
| AB-004 | 解码后恰好 15 MiB 与超过 15 MiB | 边界通过，超限拒绝 |
| AB-005 | HTTP/HTTPS 音频 URL | 保持通过且不触发上传 |
| AB-006 | 视频 Data URI 或本地路径 | 继续返回 URL 限制提示 |
| AB-007 | Gradio multipart 上传 | 字段名、文件名、内容和响应路径正确 |
| AB-008 | 参数准备包含音频 Data URI | 上传路径写入对应音频槽位 |
| AB-009 | 自动重试 | 再次上传 Data URI，不复用旧缓存路径 |
| AB-010 | 上传异常和超大响应 | 返回受控错误，不泄漏媒体内容 |

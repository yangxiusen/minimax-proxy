## 3. 页面结构

1. 顶栏：产品名、最后更新时间、管理员和退出入口。
2. 全部任务：筛选、搜索、任务表格和 10/20 分页。
3. 私有服务监控：独立外层容器，左侧节点列表，右侧选中节点详情。
4. 节点任务：当前任务单独展示，下方仅展示最近一条已结束任务。

## 4. 状态与交互

- 加载态：保持稳定布局，数值使用占位符。
- 空态：任务列表显示“暂无任务”，节点最近任务显示“暂无已结束任务”。
- 错误态：保留最后成功缓存并标记过期；节点连接失败使用红色状态，不显示伪造资源值。
- 权限：未登录跳转登录页；页面无写操作按钮。
- “查看完整记录”通过设置上方实例筛选实现，不增加节点内分页。

## 5. 对接字段

页面依赖会话接口、监控快照接口和管理任务列表接口。时间使用本地时区显示，接口仍返回 Unix 时间或 RFC3339；`api_key_id` 可展示，真实 Key 不得输出。

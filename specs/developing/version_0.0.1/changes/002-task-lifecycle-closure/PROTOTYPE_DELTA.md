# 监控任务操作原型增量

## 1. 页面变化

任务表格在“创建时间”后增加固定宽度“操作”列：

- 活动任务显示“中止”按钮。
- `cancelled/succeeded/failed` 显示“删除”按钮。
- 成功且有公开视频地址时额外显示播放图标按钮。
- 无可用操作时显示 `--`，保持列宽稳定。

状态列新增“提交中”“恢复中”“重试 1/1”“中止中”标签。窄屏保持横向滚动，不压缩任务 ID和操作按钮到不可读。

## 2. 交互状态

- 中止确认：提示“将尝试中止模型任务；模型服务不可用时会强制结束本地任务并释放实例。确认中止？”
- 删除确认：提示“删除后任务将不再显示，但不会删除模型服务器上的视频文件。确认删除？”
- 操作进行中：当前行按钮禁用并显示处理中，定时刷新不得再次发起请求。
- 操作失败：保留当前列表并显示简短错误提示；409 时立即刷新该行状态。
- 播放：新标签页打开 `video_url`，缺失 URL 时不显示按钮。

## 3. 可访问性与安全

按钮必须有可见文本或 `aria-label/title`；确认对话框可由键盘操作。外部视频链接使用 `noopener noreferrer`。页面不展示模型 `job_id`、内部视频 URL或原始上游错误。

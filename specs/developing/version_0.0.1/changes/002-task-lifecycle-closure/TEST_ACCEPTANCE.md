# 任务生命周期闭环测试与验收准备

| 项目 | 内容 |
| --- | --- |
| 版本/变更 | `002-task-lifecycle-closure` |
| 测试范围 | 数据迁移、Jobs 客户端、Worker 恢复、管理接口、监控页面 |
| 状态 | 自动化验证通过，真实模型故障演练待人工确认 |

## 2. 自动化测试范围

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| TC-001 | 提交前后唯一新增模型 job | 保存 job ID并进入运行中 |
| TC-002 | 模型 job 排队、运行、完成、失败、取消 | 分别继续、成功或失败，不误判 |
| TC-003 | 私有服务离线后恢复，原 job 仍存在 | 继续原任务，不重复提交 |
| TC-004 | 服务恢复后 job 丢失但 Gallery 已新增 | 绑定结果并成功，不重试 |
| TC-005 | job 丢失且无结果 | 自动重试一次并持久化次数 |
| TC-006 | 重试任务再次丢失 | 标记失败并释放实例 |
| TC-007 | 私有服务持续离线 10 分钟 | 标记明确失败，不永久恢复中 |
| TC-008 | job 持续运行超过 10 分钟 | 精确取消后失败，不消耗自动重试机会 |
| TC-009 | 前置服务在重试提交前后重启 | 重试次数不丢失，不出现第三次提交 |
| TC-010 | 管理中止与 Worker 完成并发 | 只有一个终态获胜，不覆盖终态 |
| TC-011 | 中止排队/运行/恢复任务 | 最终已中止并释放队列或实例 |
| TC-012 | 删除 cancelled/succeeded/failed | 软删除成功，幂等关系清理 |
| TC-013 | 删除活动任务或中止终态任务 | 返回 409，不修改数据 |
| TC-014 | 管理任务列表能力和视频字段 | 状态能力正确，只返回公网 URL |
| TC-015 | 旧数据库存在无 job ID活动任务 | 迁移后可兼容恢复并闭环 |
| TC-016 | Jobs API不可用或中止结果不确定 | 节点保持不可调度，确认私有端空闲后才恢复 |
| TC-017 | Jobs 历史持续增长 | 每次快照最多读取和保存最近 256 条任务 |

## 3. 安全与数据一致性

- 未登录管理写接口返回 401。
- 非法任务 ID返回 404/400，不拼接 SQL 或私有 URL。
- 日志和响应不得包含 prompt、媒体 URL、完整 Jobs 响应、私有地址和 API Key。
- 所有网络调用均不持有 SQLite 写事务。
- `cancelling` 仍受活动实例唯一索引约束。

# 管理后台与节点配置原型增量

> 节点表单凭据字段已由 `006-node-single-key-conf` 修订为单个 32 位 API Key，Key ID 字段不再展示；本文旧字段仅用于历史追溯。

## 1. 页面框架

页面标题改为“MiniMax H3 管理后台”，主内容继续使用现有任务列表和私有服务监控布局。顶栏右侧按以下顺序排列：

```text
[数据更新时间]  [配置]  管理员  [退出]
```

“配置”是明确命令按钮，点击后打开模态弹窗。桌面端弹窗宽度不超过 960px；窄屏使用接近全屏的纵向布局，内容可滚动，底部操作区固定可见。

## 2. 配置弹窗

弹窗标题为“模型服务节点配置”，由节点列表和编辑表单组成：

```text
┌ 模型服务节点配置 ────────────────────────────── × ┐
│ 节点列表                 节点信息                  │
│ [+ 新增节点]             节点 ID       [gpu-1]    │
│ ● gpu-1  已启用          Gradio 地址   [......]   │
│ ○ gpu-2  已停用          Jobs 地址     [......]   │
│                          公开视频地址  [......]   │
│                          健康路径      [/]        │
│                          提交接口名    [......]   │
│                          查询接口名    [......]   │
│                          轮询间隔      [3s]       │
│                          请求超时      [30s]      │
│                          [启用节点]               │
│                                                     │
│                    [测试连接] [删除] [取消] [保存] │
└─────────────────────────────────────────────────────┘
```

节点列表项显示节点 ID、启停状态和未保存修改标记。新增模式使用默认接口名、`/` 健康路径、`3s` 轮询间隔和 `30s` 请求超时；节点 ID 在编辑模式只读。

## 3. 交互规则

- 打开弹窗时加载节点配置，并默认选中监控页当前节点；没有当前节点时选中第一项。
- 切换节点、关闭弹窗或刷新配置前，如表单有未保存修改，必须二次确认。
- “测试连接”使用当前表单草稿，不要求先保存；测试期间禁用重复提交，并分别反馈 Gradio 和 Jobs 检查结果。
- “保存”通过后关闭或保留弹窗均可，但必须刷新节点列表和监控快照，并显示“配置已保存，正在检查节点状态”。
- 启用改为停用时提示“节点将不再领取新任务，当前任务仍会继续收口”。
- 删除按钮仅在已停用节点显示；点击后二次确认，存在活动任务时保留弹窗并展示后端冲突提示。
- 版本冲突后不覆盖服务端值，提示用户重新加载。

## 4. 页面状态

| 状态 | 展示与行为 |
| --- | --- |
| 节点为空 | 节点监控区显示“尚未配置模型服务节点”和“新增节点”按钮 |
| 加载中 | 固定高度骨架或加载文字，页面布局不跳动 |
| 加载失败 | 保留已有缓存内容并显示重试按钮 |
| 配置应用中 | 节点状态旁显示“应用中”，不计入健康节点 |
| 已停用 | 显示中性“已停用”标签，不计入异常节点 |
| 健康未知 | 显示“状态未知”，等待首次采集 |
| 字段错误 | 错误紧邻字段，焦点移动到首个错误 |

## 5. 可访问性与安全

- 弹窗打开后焦点进入标题或首个可编辑字段，Tab 不离开弹窗，Escape 关闭前检查未保存修改。
- 关闭、保存、删除和测试按钮有清晰可见文本；状态不能只靠颜色表达。
- URL 输入关闭浏览器自动填充，不在 DOM 属性、查询参数或错误信息中拼接节点地址。
- 删除、停用和放弃修改使用可键盘操作的确认对话框。

## 6. H3 节点凭据与升级交互修订

### 6.1 H3 节点表单

H3 节点使用以下字段替代旧 Gradio/Jobs 字段：节点 ID、服务地址、协议版本、Key ID、Secret、轮询间隔、请求超时和启用开关。Secret 永不回显；编辑已有 H3 节点时显示“已配置”状态，留空表示沿用的前提是后端确认已有完整密钥。

Key ID 字段下方只展示字段错误，不展示 Secret 获取说明。管理员可以在 MiniMax-H3 部署配置中确认 Key ID，并使用生成摘要前的原始 Secret。

### 6.2 旧节点状态

旧节点显示 `legacy-gradio-v1` 和“待升级”状态。普通编辑只允许启停，连接字段保持只读；提供独立“升级协议”命令。升级对话框明确要求服务地址、Key ID 和新 Secret，提交按钮使用“升级并保存”，避免用户把协议转换误认为普通保存。

### 6.3 反馈状态

| 场景 | 页面反馈 |
| --- | --- |
| 缺少升级 Secret | Secret 字段显示“升级到 H3 Node API 时必须填写新密钥” |
| Key ID 含点号或超过 64 位 | Key ID 字段显示格式错误 |
| 凭据认证失败 | 测试结果显示“凭据无效”，不回显节点响应 |
| 权限不足 | 测试结果列出缺失的安全 scope 名称 |
| 保存成功、探测未完成 | 显示“应用中”，不提前标记健康 |
| 服务端版本冲突 | 保留草稿，提示重新加载最新配置 |

生成配置页面移除 CFG 数值框。现有配置详情如含历史 CFG，只在兼容数据中忽略，不在可编辑界面展示。

## 7. 已完成任务播放交互

### 7.1 任务列表操作

已成功且 `video_url` 可用的任务操作区按以下顺序显示：

```text
[播放] [删除]
```

- “播放”使用明确文本按钮，保留现有紧凑任务表布局。
- 排队、运行、失败、取消或没有可访问制品的任务不显示“播放”。
- 播放不触发任务状态变更，不需要确认对话框。

### 7.2 播放弹窗

```text
┌ 视频播放 · 272076440301631191 ───────── [关闭] ┐
│                                                │
│            <video controls>                    │
│                                                │
│  正在加载 / 视频加载失败，请关闭后重试          │
└────────────────────────────────────────────────┘
```

- 桌面宽度不超过 960px；视频保持原始比例，最大高度不超过可视区，移动端不横向溢出。
- 使用原生 controls，不额外绘制播放、音量或全屏符号。
- 打开时焦点进入关闭按钮或播放器；Escape 和关闭按钮均关闭弹窗。
- 加载中显示中性状态，`canplay` 后隐藏；`error` 显示“视频加载失败，请关闭后重试”。
- 关闭时暂停、清空 `src`、调用 `load()`，清除任务 ID 和错误状态，避免后台继续下载或播放。
- 任务列表每 5 秒刷新时，已打开的播放器不重新绑定 URL、不闪烁、不关闭。
- 签名过期时只影响尚未发起的后续请求；重新关闭并点击播放会从最新列表取得新签名 URL。

### 7.3 空态与异常态

| 场景 | 页面行为 |
| --- | --- |
| 成功任务无 artifact | 不显示播放，不展示无效按钮 |
| 签名生成失败导致列表失败 | 保留现有缓存列表并标注缓存状态 |
| 视频 401/403/404/410/5xx | 弹窗统一显示加载失败，不泄露响应正文 |
| 浏览器不支持视频格式 | 显示加载失败，用户可关闭弹窗 |

# 管理监控端

## 页面索引

- [`index.html`](index.html)：原型入口。
- [`monitor.html`](monitor.html)：只读监控主页面。

## 产品元素标准

- 风格：克制、运维导向，以高信息密度和可扫描性为主。
- 色板：白色内容面、浅灰页面底色；蓝色表示选中/运行，绿色表示健康/成功，红色表示异常，琥珀色表示排队或警告。
- 字体：系统无衬线字体；正文 13-14px，表头 12px，页面标题 18px；字间距为 0。
- 间距：以 8px 为基础单位；区域间距 16px；边框圆角不超过 6px。
- 组件：筛选控件、数据表、分页、节点列表、资源指标和状态标签。
- 状态：必须覆盖加载、空数据、健康、异常、未知和缓存过期。
- 反馈：页面每 5 秒自动刷新并展示最后更新时间；只读页面不提供任务或节点操作按钮。

完整任务历史统一在顶部列表中按实例筛选。节点详情只展示当前任务和最近一条已结束任务，不设置节点内分页。

# 项目概览

## 基本信息

- 项目名称：`minimax-h3-tc`
- 项目类型：接口中转与协议适配 API 服务
- 创建日期：2026-08-06
- 当前状态：`v0.0.1` 需求已定义，待技术方案设计
- 技术栈：Go、SQLite、YAML 配置、Docker

## 项目描述

将私有部署的 MiniMax-H3 本地 Gradio API 包装为稳定的对外服务 API。上游服务地址通过环境变量配置，部署应尽量保持单容器、低依赖和易迁移。

## 核心能力

- 对外兼容目标 MiniMax V2 视频生成接口。
- 完成请求校验、参数映射、鉴权和统一错误响应。
- 生成本地任务 ID，维护任务队列、状态和结果归属。
- 调用私有 MiniMax-H3 API 并轮询异步结果。
- 使用 SQLite 持久化任务、密钥标识、幂等记录和必要审计信息。
- 调度多个独占的私有服务实例并行执行，每个实例一次只运行一个任务。
- 提供 Docker 化运行、环境变量配置和关键链路日志。

## 开发规范摘要

所有文件使用 UTF-8；代码注释使用中文；关键代理边界必须记录可关联、已脱敏的结构化日志；运行时代码不得直接依赖 `docs/`。

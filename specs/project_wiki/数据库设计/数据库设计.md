# 数据库设计

## 分类目标

定义低依赖本地持久化方案，支撑任务恢复、状态查询、所有权隔离和审计。

## 当前范围

- 实现方向：SQLite 单文件数据库，通过 Docker Volume 持久化。
- 核心实体：视频生成任务、结果 URL 映射、API Key 标识和幂等记录；首版不包含独立文件或回调投递表。
- 核心状态：`queued`、`running`、`succeeded`、`failed`、`cancelled`。

## 设计约束

- SQLite 启用 WAL、外键和 busy timeout，业务写事务使用 `BEGIN IMMEDIATE`。
- `video_tasks` 保存队序、内部状态、上游归属、Gallery 基线和结果 URL。
- `idempotency_keys` 以 API Key、幂等键摘要唯一，并按配置窗口过期。
- 部分唯一索引保证每个上游最多一个活跃任务；所有权查询同时过滤 `api_key_id`。
- 任务超过 7 天后逻辑删除，不负责删除私有服务中的物理视频。

字段、索引、事务边界和迁移策略见 [`DATABASE_DESIGN.md`](../../developing/version_0.0.1/DATABASE_DESIGN.md)。

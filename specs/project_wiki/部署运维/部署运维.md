# 部署运维

## 分类目标

提供尽量无外部依赖的 Docker 部署和运行维护方式。

## 当前约束

- 单容器部署优先，暴露一个对外 HTTP 端口。
- 上游私有服务基础地址必须通过环境变量配置。
- SQLite 数据库和必要日志通过 Volume 持久化；中转服务不保存或代理视频文件。
- 每个 MiniMax-H3 节点的 `service_url` 必须同时可被 Proxy 和下载客户端访问；生产环境应使用 HTTPS。查询接口会基于该地址返回 48 小时有效的节点签名直链。
- 提供配置示例，但真实密钥不得进入镜像或版本库。
